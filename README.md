# GSI (Get, Save, and Invest)

A personal financial tracking and discipline platform designed to track where every unit of money goes and enforce positive-yield financial accountability.

## Features

- **Strict Yield Gatekeeper**: Every withdrawal must specify its source, reason, benefit, and expected monetary yield. The system strictly blocks any withdrawal where `Expected Yield <= Withdrawal Amount`.
- **Post-Expense Accountability & Audit**: Directly review past withdrawals, tick whether the goal was achieved, and record actual money earned and success extent.
- **Job & Earning Profitability Tracker**: Track expected salary or contract earnings against all direct work expenses (transport, food, clothes, data, utility bills) to evaluate true take-home earnings and avoid running at a loss.
- **Asset Productivity Tracker**: Register assets (laptop, car, book, phone) and log lifetime earnings generated to verify whether purchases paid for themselves.
- **Target Savings Goals**: Set savings targets for intended purchases, record deposits, and track progress. Features expressive accountability feedback on withdrawals.
- **Multi-Currency Support**: Supports 20 currencies including Naira (₦), US Dollar ($), Euro (€), Pound (£), Yen (¥), and top cryptocurrencies (BTC ₿, ETH Ξ, USDT ₮, BNB, SOL).
- **Responsive Collapsible Sidebar**: Fast, clean Google-style navigation that can be expanded or confined with SVG vector icons.
- **No Complex Dependencies**: Pure HTML, CSS, and Vanilla JavaScript—runs directly in any browser or static web server.

## Getting Started

Simply open `index.html` in your browser, or run a local server:

```bash
# Python
python -m http.server 3000

# Or Node.js
npx serve .
```

Visit `http://localhost:3000` to start keeping records.
